## 📌 Project Overview

This project is an interactive **Streamlit Dashboard + Machine Learning Prediction App** built using a dataset on:

👉 **Freelancer Income vs Skills**

It analyzes how:

* skills
* experience
* hourly rate
* region & country
* platform

impact **annual freelancer income**, and also allows users to **predict income using ML models**.

---

## 🔹 Key Features

✔ Interactive dashboard (multi-page)
✔ Dynamic charts & filters
✔ EDA & data visualization
✔ Country & region wise analysis
✔ ML regression model
✔ Annual income prediction
✔ Feature importance visualization

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/freelancer-income-ml-app.git
```

2️⃣ Navigate to folder

```bash
cd freelancer-income-ml-app
```

3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

4️⃣ Run the app

```bash

```
